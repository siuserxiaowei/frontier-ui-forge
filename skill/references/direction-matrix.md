# Direction matrix

Use this file when the brief is open, the first ideas look interchangeable, or the user asks for options.

## Required columns

| Axis | Direction A | Direction B | Direction C |
|---|---|---|---|
| Composition | named structure and focal path | named structure and focal path | named structure and focal path |
| Typography | display/body pairing, scale, measure | display/body pairing, scale, measure | display/body pairing, scale, measure |
| Color | surface, text, accent, semantic colors | surface, text, accent, semantic colors | surface, text, accent, semantic colors |
| Material | borders, depth, texture, imagery | borders, depth, texture, imagery | borders, depth, texture, imagery |
| Motion | one product-relevant moment | one product-relevant moment | one product-relevant moment |

## Separation gate

For every pair, mark whether each axis is materially different. At least three of five axes must differ. A new accent color alone is not a new direction. A different hero image with the same skeleton, type, and spacing is not a new direction.

## Selection score

Score every direction from 0 to 10:

- task fit: 30 percent;
- hierarchy and comprehension: 20 percent;
- distinctive identity: 20 percent;
- buildability and maintainability: 15 percent;
- accessibility and responsive confidence: 10 percent;
- novelty after context: 5 percent.

Record the winning direction, the rejected directions, the tradeoff accepted, and the single memorable moment to preserve.

## Anti-convergence prompts

- Change the dominant composition, not only the palette.
- Change the typographic voice, not only the font size.
- Change information density and grouping, not only card radius.
- Replace decoration with a material or interaction that belongs to the product.
- Keep one quiet region so the focal region has room to speak.
